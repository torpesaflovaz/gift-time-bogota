# Administrar Gift Time Bogotá

1. Publica esta carpeta en la raíz del repositorio `gift-time-bogota`.
2. Abre `https://gifttimebogota.com.co/admin.html`.
3. Crea un token de GitHub de tipo **fine-grained** para la cuenta `torpesaflovaz`:
   - Acceso a repositorios: **Solo repositorios seleccionados** → `gift-time-bogota`.
   - Permisos del repositorio: **Contents / Contenido → Read and write**.
   - Ponle vencimiento (por ejemplo, 90 días) y un nombre como `Gift Time Admin Mac`.
4. Copia el token y pégalo en el panel. No lo compartas por WhatsApp ni lo agregues a los archivos del repositorio.
5. Pulsa **Cargar catálogo**. Ya puedes agregar, editar o borrar productos.
6. Al terminar, pulsa **Publicar cambios en GitHub**. La tienda se actualiza sola en 1–2 minutos.

## Usarlo desde otro dispositivo

Crea otro token con el mismo permiso, pero un nombre diferente, por ejemplo `Gift Time Admin Celular`. Abre el mismo `admin.html`, pega ese token una vez y úsalo normalmente.

El panel guarda el token únicamente en el navegador del dispositivo. Si borras los datos de navegación o cambias de equipo, tendrás que pegarlo otra vez.

## Importante

- El estado **Sobre pedido** permite que el cliente lo agregue al pedido, sin descontar inventario.
- El estado **Agotado** no permite añadirlo al carrito.
- Al borrar un producto, la foto antigua puede permanecer en GitHub, pero deja de verse en la tienda.
- Si otra persona publicó cambios mientras estabas editando, el panel te pedirá recargar el catálogo para evitar sobrescribirlos.
